# AI Agents

This section is for coding agents that need to build or maintain Documentee docs by reading the repository.

## Reading Order

1. Read `AGENTS.md` at the repository root.
2. Read [Configuration](/configuration).
3. Read the [Config Reference](/api-reference/config).
4. Read the [CLI Reference](/api-reference/cli).
5. Read [Architecture](/contributing/architecture), [Testing](/contributing/testing), and [Small HTML Policy](/contributing/small-html-no-client-js).
6. Read the package README that owns the area you are editing.

## Working Rule

Docs changes should be made in `docs/` and reflected in `documentee.config.ts` navigation when a new primary page is added.

If a config field changes, update [Config Reference](/api-reference/config). If a CLI command changes, update [CLI Reference](/api-reference/cli). If renderer behavior changes, check the small HTML policy.

## AI Outputs

Static builds emit `llms.txt`, `llms-full.txt`, `llms.json`, and `skill.md`. Use `llms.json` when an agent needs a machine-readable route index with guide pages and API operations. Its route entries include semantic chunks with heading paths, source files, text, links, and compact API operation metadata when available. Use `skill.md` when an agent needs a compact project overview, reading order, important routes, verification commands, and contribution rules. Excluded content stays out of these outputs because it is filtered before the manifest is rendered.

## Local MCP Server

Generate a local read-only MCP server when an AI coding tool should search the current docs directly:

```bash
documentee generate-mcp . --out .documentee-mcp
```

The generated folder contains `llms.json`, `server.mjs`, package metadata, and a README. Its tools are `search_docs(query)`, `read_doc(route)`, `list_api_operations()`, and `read_api_operation(method, path)`.

## Verification

Before claiming docs work is complete, run:

```bash
pnpm docs:validate
pnpm validate
pnpm docs:build
pnpm test
```

Continue with the full repository verification from `AGENTS.md` when the docs change is part of a code change.
