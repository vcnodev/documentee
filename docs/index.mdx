# Documentee

Documentee is an open-source documentation generator for small static HTML docs, OpenAPI references, and AI-readable outputs.

Use it when you want a Mintlify-style documentation project that can be built locally, deployed as static files, and maintained by humans or coding agents.

## What Documentee Builds

- Static Markdown and MDX documentation.
- Responsive, themeable static HTML.
- OpenAPI 3.0 and 3.1 operation pages.
- Multi-spec API portals and versioned docs.
- `llms.txt` and `llms-full.txt` for AI-readable consumption.
- Pagefind search when explicitly enabled.
- Optional browser API playground UI for individual OpenAPI specs.
- Migration, audit, feedback, analytics, and comparison surfaces for launch-ready docs projects.
