# Use Documentee

This page is the compact operating manual for Documentee. It is generated by Documentee itself, can be published to GitHub Pages, and is structured so humans and LLMs can quickly learn how to use this app.

## What To Build

Use Documentee when you want static documentation that stays easy to review in Git, easy to host anywhere, and easy for coding agents to read.

Documentee builds:

- Static Markdown and MDX docs.
- OpenAPI 3.0 and 3.1 API references.
- Versioned, searchable, themeable documentation sites.
- AI-readable outputs: `llms.txt`, `llms-full.txt`, `llms.json`, and `skill.md`.
- Optional browser API playground pages when an OpenAPI spec opts in.

## Minimum Project Shape

Create content in `docs/`, configure the site in `documentee.config.ts`, then build to static HTML:

```bash
pnpm install
pnpm docs:validate
pnpm docs:build
pnpm docs:preview
```

For this repository, open `http://127.0.0.1:3000/documentee/` after `pnpm docs:preview` so local routing matches the GitHub Pages base path.

The root `documentee.config.ts` is the source of truth for this dogfood site. External projects usually start with:

```ts
export default {
  site: {
    name: "Acme Docs",
    description: "Static docs for humans and AI agents.",
  },
  content: { directory: "docs" },
  navigation: [
    { group: "Start", pages: ["docs/index", "docs/get-started/quickstart"] },
  ],
  search: { provider: "pagefind" },
  theme: {
    designSystem: "minimal-technical",
    overrides: { primaryColor: "#2563eb" },
    darkMode: true,
  },
};
```

Read [Configuration](/configuration) and the [Config Reference](/api-reference/config) when you add navigation, OpenAPI specs, search, themes, SEO, redirects, assistant, feedback, analytics, or plugins.

## LLM Reading Path

Give an LLM these files or routes in this order:

1. `AGENTS.md`
2. `/get-started/use-documentee`
3. `/configuration`
4. `/api-reference/config`
5. `/api-reference/cli`
6. `/api-reference/openapi`
7. `/ai-agents`
8. `/ai-agents/doc-builder-guide`

For generated machine-readable context, point the LLM at:

- `llms.txt` for a compact site map.
- `llms-full.txt` for full extracted text.
- `llms.json` for structured routes, chunks, links, and API operation metadata.
- `skill.md` for a compact agent skill-style overview.

These files are emitted by `pnpm docs:build` into `dist-docs/`.

## Host On GitHub Pages

This repository includes `.github/workflows/pages.yml` to build and publish the generated `dist-docs/` directory.

To enable it in GitHub:

1. Open the repository on GitHub.
2. Go to **Settings**.
3. Open **Pages**.
4. Under **Build and deployment**, set **Source** to **GitHub Actions**.
5. Push to `main` or run the workflow manually.

The workflow validates the dogfood docs, builds them with Documentee, uploads `dist-docs/` as a Pages artifact, and deploys it with GitHub Pages.

## Deployment Checklist

Before publishing a consumer-facing docs site:

- Run `pnpm docs:validate`.
- Run `pnpm docs:build`.
- Run `pnpm docs:preview` and click through primary routes locally.
- Confirm `dist-docs/index.html` exists.
- Confirm `dist-docs/llms.txt`, `dist-docs/llms-full.txt`, `dist-docs/llms.json`, and `dist-docs/skill.md` exist.
- Confirm GitHub Pages is configured to use GitHub Actions.
