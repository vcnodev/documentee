# Components

Documentee supports a practical set of MDX-style components by transforming them into static HTML.

## Core Components

- `Callout`
- `Steps` and `Step`
- `Tabs` and `Tab`
- `CodeGroup`
- `Accordion` and `AccordionGroup`
- `Card` and `CardGroup`
- `ParamField`
- `ResponseField`
- `Frame`
- `Icon`
- `Badge`
- `PackageInstall`
- `CliCommand`
- `Mermaid`
- `Update` and `Changelog`
- `Columns` and `Column`
- `FeatureGrid` and `Feature`
- `EndpointCard`
- `OpenApiOperation`

## Migration Compatibility

Documentee also recognizes common framework components:

- Docusaurus `DocCardList` and `Admonition`.
- Nextra `FileTree`, `Folder`, `File`, `Pre`, and `CodeBlock`.
- Mintlify `Expandable`, `Snippet`, `RequestExample`, and `ResponseExample`.

## Example

```mdx
<CardGroup cols="2">
<Card title="Config Reference" href="/api-reference/config">Read every config field.</Card>
<Card title="Agent Guide" href="/ai-agents">Maintain docs with agents.</Card>
</CardGroup>
```

`CardGroup` honors explicit column counts on desktop and collapses to one column on narrow screens. Decorative card icons are hidden from assistive technology while the card title and description remain readable.

```mdx
<PackageInstall package="documentee" managers="pnpm,npm,yarn" />

<CliCommand command="documentee build . --out dist" />

<FeatureGrid>
  <Feature title="Static output" icon="check">No hydration required.</Feature>
  <Feature title="Agent-ready" icon="code">LLM files ship with builds.</Feature>
</FeatureGrid>

<EndpointCard method="POST" path="/messages" href="/api-reference/core/create-message">
Create a message.
</EndpointCard>
```

`Mermaid` renders a static code block with `language-mermaid` so teams can bring their own diagram enhancement later without Documentee shipping client JavaScript by default.

## Generated Page UI

The renderer adds static heading anchors and an "On this page" navigation from `h2` and `h3` headings. Wide docs pages show the page navigation beside the content. Narrow screens show it as a compact disclosure above the page body.

Mobile pages include a top navigation bar with search and a menu disclosure so readers can reach site navigation without scrolling to the bottom of a page.

Generated pages also include breadcrumbs and previous/next page links derived from configured navigation. Rendered code blocks get a lightweight copy button when code is present.

API reference navigation includes endpoint grouping and filtering for larger specs. API playground results expose loading, success, and error states without storing secrets in browser storage.

The renderer emits static HTML and CSS. Components do not require client hydration.
