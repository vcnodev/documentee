# Documentee vs Nextra

Nextra is a Next.js and MDX framework for building content-focused sites with strong Next.js defaults. Documentee is a docs generator built around Markdown, MDX-style static components, OpenAPI, and AI-readable outputs.

## Choose Documentee when

- You want a docs pipeline that can run without adopting Next.js.
- You want OpenAPI operation pages, schema pages, and multi-spec API portals generated from config.
- You want AI-readable outputs and MCP generation as first-class artifacts.
- You prefer constrained static rendering over a full application framework.

## Choose Nextra when

- You want to build on Next.js and use its routing, rendering, image, link, and deployment ecosystem.
- You want MDX-centered docs with the flexibility to grow into a custom Next.js site.
- Your team is already comfortable maintaining a Next.js app.

## Honest Positioning

Documentee trades framework flexibility for a focused static docs workflow. Nextra trades more application surface area for deeper Next.js integration.
