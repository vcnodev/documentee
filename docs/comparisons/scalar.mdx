# Documentee vs Scalar

Scalar focuses on OpenAPI-powered API interfaces, including beautiful docs, SDKs, MCP servers, and developer portal workflows. Documentee focuses on portable static docs, OpenAPI reference generation, and AI-readable artifacts that live in the repository.

## Choose Documentee when

- You want OpenAPI docs that build to static files and can be deployed on any static host.
- You want guides, API references, search, feedback, analytics hooks, audit reports, and AI-readable outputs in one deterministic local build.
- You want to keep generated agent context in files such as `llms.json`, `skill.md`, and a local MCP server folder.

## Choose Scalar when

- Your primary need is a dedicated API interface platform around OpenAPI.
- You want SDK and API client workflows from the same vendor surface.
- You want hosted product workflows around API interfaces.

## Honest Positioning

Documentee is a lightweight, static-first docs generator. Scalar has a deeper API-interface product surface. Documentee should appeal to teams that want ownership and portability; Scalar should appeal to teams that want a specialized API platform.
