# Documentee vs Docusaurus

Docusaurus is a React-powered static-site generator for documentation websites, blogs, and content-heavy sites. Documentee is narrower: it focuses on static docs, OpenAPI references, and AI-readable outputs from a shared manifest.

## Choose Documentee when

- You want API reference generation from OpenAPI as a first-class workflow.
- You want `llms.txt`, `llms-full.txt`, `llms.json`, `skill.md`, and local MCP generation built into the docs pipeline.
- You want the default static renderer to avoid Documentee client JavaScript unless a feature explicitly opts in.
- You want audits for broken links, metadata gaps, private content exposure, oversized pages, search readiness, and OpenAPI examples.

## Choose Docusaurus when

- You want a broad React site framework for docs, blogs, landing pages, plugins, and custom interactive UI.
- Your team already works deeply in React and wants that component ecosystem in the docs app.
- You need a large existing community and plugin surface.

## Honest Positioning

Documentee is more opinionated and smaller. Docusaurus is more general and more extensible. The right choice depends on whether your docs are primarily an API and agent-readable artifact, or a larger React website.
