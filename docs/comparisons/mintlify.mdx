# Documentee vs Mintlify

Mintlify is a polished hosted documentation platform with AI-native positioning, smart search, interactive API docs, and team workflows. Documentee is an open-source static generator for teams that want docs they can build locally, deploy anywhere, inspect as plain files, and feed directly to coding agents.

## Choose Documentee when

- You want a fully local, static-first build with no hosted control plane requirement.
- You want generated `llms.txt`, `llms-full.txt`, structured `llms.json`, `skill.md`, and local MCP output in the repository workflow.
- You want OpenAPI reference pages, docs pages, search, feedback, analytics hooks, and audit reports without shipping Documentee client JavaScript by default.
- You want a tool that is easy for agents to modify because content, config, and generated outputs are deterministic.

## Choose Mintlify when

- You want a managed hosted documentation platform with built-in collaboration, hosting, and commercial support.
- You want a mature out-of-the-box visual system and hosted AI/search experience.
- You prefer buying a documentation platform over owning the build pipeline.

## Honest Positioning

Documentee aims to win on portability, local builds, small static HTML, AI-readable outputs, and open-source control. Mintlify currently wins for teams that want managed hosting, a mature commercial product surface, and less build ownership.

Reference: [Mintlify documentation](https://www.mintlify.com/docs).
