# Configuration

Documentee reads `documentee.config.ts`, `documentee.config.js`, or `docs.json` from the project root. TypeScript config is the best fit for this repository because it is easy for agents and humans to review.

```ts
export default {
  site: {
    name: "Documentee",
    url: "https://documentee.dev",
    basePath: "/documentee",
    description: "Static docs for humans and AI agents.",
  },
  content: { directory: "docs" },
  navigation: [
    { group: "Start", pages: ["docs/index", "docs/get-started/quickstart"] },
    { group: "Reference", pages: ["docs/api-reference/config"] },
  ],
  search: { provider: "pagefind" },
  theme: {
    designSystem: "minimal-technical",
    overrides: { primaryColor: "#2563eb" },
  },
};
```

Set `site.basePath` when the site is hosted below a domain path, such as GitHub Pages project sites at `https://owner.github.io/repo`. For a user or custom-domain site hosted at the domain root, omit `basePath`.

## Content And Navigation

`content.directory` controls where Markdown and MDX pages are loaded from. Navigation groups point to source files or absolute routes.

Use source references for docs pages:

```ts
{ group: "Start", pages: ["docs/index", "docs/get-started/quickstart"] }
```

Use absolute routes when a page is generated or easier to name directly:

```ts
{ group: "Versions", pages: ["/v1"] }
```

## Theme

`theme.designSystem` selects a complete visual baseline. It can be `minimal-technical`, `modern-glass`, `api-ide`, `enterprise-knowledge`, `premium-editorial`, `sci-fi-console`, `api-observatory`, or `knowledge-graph`.

Use `theme.overrides` for local tuning:

```ts
theme: {
  designSystem: "api-ide",
  overrides: {
    primaryColor: "#2563eb",
    navWidth: "300px",
    radius: "8px",
    contentWidth: "1040px",
    methodGetColor: "#22c55e",
  },
  darkMode: true,
}
```

Overrides win over design-system tokens. Use them for brand colors, fonts, layout density, content width, card radius, shadows, API method colors, and custom CSS. Existing flat token fields and `theme.preset` are still accepted for migration compatibility, but new configs should use `designSystem` plus `overrides`.

## Search

Set `search.provider` to `pagefind` to emit a `/search/` route and build Pagefind assets. Ordinary docs pages show a static suggestion modal from the sidebar search control; only `/search/` loads the full Pagefind UI scripts.
