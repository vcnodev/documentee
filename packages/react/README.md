# @documentee/react

Server-rendered React primitives for Documentee.

The package is designed for small HTML output and no Documentee client-side JavaScript. It should consume the shared manifest from `@documentee/core` rather than reimplementing content, OpenAPI, or validation behavior.

See the [root README](../../README.md) and [small HTML policy](../../docs/contributing/small-html-no-client-js.md).
