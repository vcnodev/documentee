# @documentee/llms

Generates AI-readable `llms.txt` and `llms-full.txt` outputs from a Documentee site manifest.

These files summarize generated docs, API operation routes, schema routes, and source Markdown so LLM tools can inspect the documentation without crawling the rendered site.

See the [root README](../../README.md) and [architecture notes](../../docs/contributing/architecture.md).
