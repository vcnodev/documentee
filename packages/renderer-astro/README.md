# @documentee/renderer-astro

Astro renderer package for Documentee.

This package consumes the shared Documentee manifest and generates Astro-ready route metadata and project files. Renderer work should preserve the same route, OpenAPI, theme, validation, and no-client-JS semantics defined in `@documentee/core`.

See the [root README](../../README.md) and [architecture notes](../../docs/contributing/architecture.md).
