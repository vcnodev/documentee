# @documentee/renderer-next

Next.js renderer adapter package for Documentee.

Provides App Router and Pages Router adapter metadata for server-rendered docs that preserve the small-HTML/no Documentee client JavaScript policy.

The package includes fixture-app regression helpers that generate real App Router and Pages Router projects, audit generated source files for client markers, and check server-rendered Documentee HTML snapshots against route-level payload budgets.

See the [root README](../../README.md) and [small HTML policy](../../docs/contributing/small-html-no-client-js.md).
